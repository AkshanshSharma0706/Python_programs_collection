# 🐍 Python Programming Projects

## 📌 Overview

Welcome to my Python Programming Projects repository! This repository contains three beginner-level Python projects developed to practice fundamental programming concepts and Object-Oriented Programming (OOP).

Each project focuses on a specific programming concept and helps build a strong foundation in Python.

## 📂 Projects

### 1. Factorial Calculator

Calculates the factorial of a given number using a `for` loop.

- **Concepts:** Loops, variables, and arithmetic operations.
- **Language:** Python 3
- **Repository:** [Factorial Calculator](https://github.com/AkshanshSharma0706/python-basic-25BCON2159f)

### 2. Fibonacci Series Generator

Generates the Fibonacci series for a specified number of terms using an iterative approach.

- **Concepts:** Loops, variables, arithmetic operations, and sequence generation.
- **Language:** Python 3
- **Repository:** [Fibonacci Series Generator](https://github.com/AkshanshSharma0706/python-basic-25BCON2159s)

### 3. Student Structure

Demonstrates how to create a `Student` class, initialize objects using a constructor, and store and display student details such as name, roll number, and marks.

- **Concepts:** Classes, objects, constructors, and instance attributes.
- **Language:** Python 3
- **Repository:** [Student Structure](https://github.com/AkshanshSharma0706/python-basic-25BCON2159)
